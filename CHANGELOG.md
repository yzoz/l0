# Changelog

Все заметные изменения в проекте документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект придерживается [семантического версионирования](https://semver.org/).

## [Unreleased]

### Added
- **Live-терминал L0** (`src/console/`): шесть живых панелей tmux — Система, API, Consumer/ingress, Confirmer/DAG, Writer/settlement, TX bot. Компактная сводка + лента последних событий на панель; ошибки выделены, повторяющиеся события группируются (`×N`).
- Телеметрия `src/console/metrics.py`: счётчики/гейджи/гистограммы с момента старта процесса, кольцевой буфер событий, сброс счётчиков при перезапуске сервиса (`run.py`), дампы `.l0/metrics/<role>.json`.
- Middleware `src/console/middleware.py` для API: запросы, классы 2xx/3xx/4xx/5xx, задержка, события без тел/подписей/полных хэшей.
- Панель Confirmer разделяет **общее число узлов графа** (только `count`, без полного обхода) и **выборку ≤100**; статистика весов и распределение считаются только по обработанной выборке; история циклов спарклайном.
- Честные пробы зависимостей `UP`/`DOWN`/`UNKNOWN` (`src/console/health.py`) для панели Система.
- Режимы просмотра: `python -m src.console --details <role>` (полная телеметрия + хвост лога), `L0_VERBOSE=1` (полные JSON TX bot), `L0_RAW=1 ./start` (сырые логи вместо TUI).
- Цветовая палитра (cyan/green/amber/red/серый) с поддержкой `NO_COLOR`, `L0_COLOR`, `--no-color`, автоматическим отключением при перенаправлении вывода и корректным сокращением на узких терминалах.
- Тесты телеметрии, middleware, рендера панелей и сброса счётчиков (`tests/test_console.py`).
- Линтер и форматтер `ruff` с конфигурацией в `pyproject.toml`.
- `pytest-cov` с конфигурацией покрытия; интеграционные тесты отвязаны от корневого `keys.py`.
- Проверки `ruff check` и `ruff format --check` в CI, а также необязательный `pip-audit`.
- `Makefile` с частыми командами, `.dockerignore` и этот `CHANGELOG.md`.

### Changed
- `./start`: панели tmux получили названия и стилизацию (акцент на активной панели, status line сессии); сохранена семантика переподключения к сессии `l0`. Сырой режим доступен через `L0_RAW=1`.
- `tx_bot.py`: компактные события с короткими id и HTTP-статусами вместо полных JSON (полные дампы — по `L0_VERBOSE=1`); телеметрия отправок, задержек, процессов/корутин.
- Логирование сервисов дополнено телеметрией (счётчики по исходам обработки), бизнес-логика, порядок MongoDB → Redis → Memgraph, ack RabbitMQ и контракты HTTP не изменены.
- `api.py`: зависимости FastAPI получаются через `Request`/`request.app.state`, убран хак `Depends(lambda: app)`.
- Раннеры `run.py` и `run.d.py`: строгая валидация аргументов, явная ошибка при неизвестном типе сервиса.
- `MongoDB.aggregate`: убран `break`, из-за которого возвращался максимум один документ.
- Логирование настроено один раз в точках входа; модули только используют `logging.getLogger`.
- Магические числа (тайм-ауты, размеры пула, веса, коэффициенты затухания) вынесены в `src/config.py`.
- `writer.py`: подтверждение выполняется в явном порядке MongoDB → Redis → Memgraph с откатом при сбое.
- README: добавлены схема архитектуры, поток транзакции, примеры REST/GraphQL и бейдж CI.

### Fixed
- Убраны `print()` из продового кода (`transactions.py`, `confirmer.py`).

- Исправлена ссылка на репозиторий в README.
