# Score Recalculation Engine

Полная реализация ТЗ «алгоритм пересчёта накопительного score в DAG Memgraph» (v1.0).

## Что внутри

`score_recalculation.py` — единый модуль, содержащий:

1. **Математическую модель**  
   `score(T) = internal_score(T) + (1/3) · Σ score(X)` по непосредственным потомкам.

2. **Три алгоритма** с общим интерфейсом `recalculate_scores(...)`:
   - `DFS_MEMO` — итеративный DFS с мемоизацией и тремя цветами (WHITE/GRAY/BLACK).
   - `TOPOLOGICAL` — Kahn-style топологический обход.
   - `BATCH_ITERATIVE` — волновой расчёт + симуляция пакетных запросов.

3. **Независимый эталон** (`reference_scores`) на `Decimal` для проверки корректности.

4. **Генераторы тестовых графов** G1–G6 + случайные DAG.

5. **Correctness suite** + **benchmark** + обоснованная рекомендация.

## Запуск

```bash
python3 score_recalculation.py
```

Ожидаемый результат: `Correctness: PASSED`, таблицы benchmark и рекомендация **TOPOLOGICAL**.

## Ключевые инварианты (реализованы)

- `MAX_DEPTH` ограничивает только кандидатов в `out`, **не** глубину вычисления зависимостей.
- Каждый узел считается один раз; каждый вклад по ребру — ровно один раз.
- Общие предки не дублируются.
- Цикл → явная ошибка, без частичного результата.
- `score == S` включается; `score < S` — нет.

## Production-рекомендация

**TOPOLOGICAL** (Алгоритм №2):

1. Пакетный BFS предков до `MAX_DEPTH`.
2. Итеративное раскрытие потомков кандидатов (UNWIND).
3. Топологический расчёт `score`.
4. Фильтрация `score >= S` → `out`.

Подробности — в выводе `make_recommendation()` и в комментариях к коду.
